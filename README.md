# Ipeleng Zembe — Bootstrap Portfolio

A responsive one-page developer portfolio built with Bootstrap 5.

## Run locally
1. Extract this folder.
2. Open `index.html` in a browser. An internet connection is needed for the Bootstrap and Google Fonts CDN resources.

## Sections
- Hero / introduction
- About and skills
- Selected projects
- Contact and footer

## Customise
Update the project descriptions, contact email, skills, and links in `index.html` to match your final project details.
